# Validation: Python vs R Implementation

This directory contains scripts to validate the Python implementation against the R reference implementation.

## Quick Start

### Prerequisites

**R requirements:**
```r
install.packages("bigsnpr")
install.packages("Matrix")
install.packages("reticulate")  # For saving numpy-compatible files
```

**Python requirements:**
```bash
pip install numpy scipy pandas matplotlib
```

### Step-by-Step Validation

#### Step 1: Generate R Reference Results

```bash
Rscript validation/generate_r_reference.R
```

This will:
- Generate synthetic test data (1000 variants, 5000 samples)
- Run LDpred2-inf, LDpred2-grid, and LDpred2-auto in R
- Save results to `validation/r_results/`

**Expected output:**
```
Generating test data...
  - Genotype matrix (5000x1000)...
  - Simulating phenotype...
  - True h²: 0.5
  - True p: 0.1
  ...
Running LDpred2-inf
  ✓ LDpred2-inf results saved
Running LDpred2-grid
  ✓ LDpred2-grid results saved
Running LDpred2-auto
  ✓ LDpred2-auto results saved
```

#### Step 2: Run Python Implementation

```bash
python3 validation/run_python_implementation.py
```

This will:
- Load the test data generated by R
- Run the Python implementation on the same data
- Save results to `validation/py_results/`

**Expected output:**
```
Loading test data...
  - Summary statistics: 1000 variants
  - LD matrix: (1000, 1000)
Running LDpred2-inf (Python)
  ✓ Results saved
Running LDpred2-grid (Python)
  ✓ Results saved
Running LDpred2-auto (Python)
  ✓ Results saved
```

#### Step 3: Compare Results

```bash
python3 validation/compare_with_r.py \
  --r-dir validation/r_results \
  --py-dir validation/py_results \
  --output-dir validation/comparison
```

This will:
- Load results from both implementations
- Compute comparison metrics (correlation, RMSE, etc.)
- Generate comparison plots
- Create a validation report

**Expected output:**
```
Comparing LDpred2-inf
  Correlation: 0.99999xxx
  Max absolute difference: x.xxe-06
  Status: ✅ PASSED

Comparing LDpred2-grid
  Parameter set 1:
    Correlation: 0.9xxxx
    Status: ✅ PASSED
  ...

Comparing LDpred2-auto
  Chain 1:
    Beta correlation: 0.9xxxx
    h² - R: 0.xxxx, Python: 0.xxxx, Diff: 0.xxxx
    Status: ✅ PASSED
```

## Interpretation

### LDpred2-inf

**Expected:**
- Correlation: > 0.9999 (near-perfect)
- Max difference: < 1e-5

**Why:** Deterministic algorithm with no randomness. Differences only due to numerical precision.

**If fails:** Check standardization formulas and linear solver implementation.

### LDpred2-grid

**Expected:**
- Correlation: > 0.95
- Prediction R² difference: < 0.01

**Why:** Stochastic Gibbs sampling. Different RNGs in R and Python lead to different samples, but should converge to similar distributions.

**If fails:** Check Gibbs sampling logic, posterior probability calculation, or dot product updates.

### LDpred2-auto

**Expected:**
- h² difference: < 0.1
- p difference: < 0.05
- Beta correlation: > 0.90

**Why:** Stochastic sampling + optimization. May converge to slightly different local optima.

**If fails:** Check MLE optimization, parameter update logic, or convergence detection.

## Troubleshooting

### R script fails

**Problem:** `Error: package 'bigsnpr' is not available`

**Solution:**
```r
install.packages("bigsnpr")
```

### Python script can't find modules

**Problem:** `ModuleNotFoundError: No module named 'ldpred2_python'`

**Solution:** Run from project root:
```bash
cd /path/to/bigsnpr
python3 validation/run_python_implementation.py
```

### Comparison shows large differences

**Possible causes:**
1. **Different random seeds** - Expected for stochastic methods
2. **Divergence** - Check for NaN in outputs
3. **Implementation bug** - Review algorithm logic
4. **Data mismatch** - Ensure using same input data

**Debug steps:**
```python
# Check if data matches
import numpy as np
import pandas as pd

df_beta_r = pd.read_csv("validation/r_results/df_beta.csv")
corr_r = np.load("validation/r_results/corr_matrix.npy")

# Verify shapes
print(f"df_beta shape: {df_beta_r.shape}")
print(f"corr shape: {corr_r.shape}")

# Check for NaN
print(f"NaN in df_beta: {df_beta_r.isna().sum().sum()}")
print(f"NaN in corr: {np.isnan(corr_r).sum()}")
```
